# Super Marine Odessy

The fast-paced gameplay of *Doom* is highly engaging, yet such games are rare in the current market. This project aims to develop a retro-style FPS inspired by *Doom*, while integrating farming elements to create a core gameplay loop: **Explore the map -> Defeat enemies to obtain items -> Farm to enhance abilities -> Better explore the map.**
